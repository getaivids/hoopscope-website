# Hoopscope Website

## Features
- Data-driven basketball training tools
- AI-powered workout plan generator (OpenAI GPT-4o)
- Blog with analytics and pro insights
- Responsive, accessible, and SEO-optimized design

## Development
- All API keys are managed via environment variables.
- To run locally, set `OPENAI_API_KEY` in your `.env` file.
- Use `npm run dev` to start the local server.

## Deployment
- All code and content are versioned and backed up to Google Drive.
- Use pull requests for all major changes.
