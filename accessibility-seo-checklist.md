# Accessibility & SEO Checklist for Hoopscope

## Accessibility
- [x] All images have descriptive alt text
- [x] Buttons and interactive elements have aria-labels
- [x] Modals use role="dialog" and aria-modal="true"
- [x] Focus is trapped within modals
- [x] Modals close on Esc key
- [x] Color contrast meets WCAG AA
- [x] Keyboard navigation is supported
- [x] ARIA live regions for dynamic AI responses

## SEO
- [x] Meta description present
- [x] Open Graph tags for social sharing
- [x] Semantic headings (h1, h2, h3)
- [x] Structured data (JSON-LD) for blog articles
- [x] Internal links between related blog posts
- [x] Sitemap.xml and robots.txt (recommended for deployment)

---

All items checked are implemented or recommended for the current release.
